# Compost Maturity Detection

## Overview
This project focuses on image-based compost maturity classification using YOLOv5 and YOLOv8.

## Technologies
- Python
- YOLOv5
- YOLOv8
- Google Colab
- OpenCV

## Dataset
Compost images were categorized into:
- Immature
- Semi-mature
- Mature

## Files
- YOLOv5.ipynb
- yolov8n.ipynb

## Future Work
- Improve classification accuracy
- Expand dataset size
