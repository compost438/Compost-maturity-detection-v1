# Compost Maturity Detection

## Overview
This repository contains a prototype implementation of an image-based compost maturity classification system using YOLOv5 and YOLOv8.

## Current Status
Prototype / Ongoing Research

## Technologies
- Python
- YOLOv5
- YOLOv8
- Google Colab
- OpenCV

## Dataset
Compost images were categorized into:
- Immature
- Semi-mature
- Mature

## Files
- YOLOv5.ipynb
- yolov8n.ipynb

## Future Work
- Improve classification accuracy
- Expand dataset size
- Integrate real-time environmental sensing
